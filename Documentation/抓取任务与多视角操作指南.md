# 紧凑任务面板、WA100 抓取与几何雷达协作

更新：2026-10-27。场景：`Assets/Underwater/Scenes/UnderwaterRadarSurveyEditable.unity`。

## 面板与三路画面

统一面板位于头显视野左上方的周边位置，宽约 0.47 m、距头部前方 1.8 m，水平视角约 15°。它是界面，会跟随头部；场景与机器人仍固定在世界中。原来独立的大雷达面板和性能 HUD 在本场景默认停用。桌面面板约 310 × 330 px。

面板同时包含一路选中的摄像头、雷达距离图带和任务状态。三路画面用标签切换，而非同时渲染三个窗口：

| 画面 | 用途 | 切换 |
|---|---|---|
| WA100 抓取近景 | 跟随手腕，看手和其下方目标/地面 | F2，或电脑面板 Hand |
| 整臂 + WA100 | 自动按 Axis1p 子树的包围范围取景，看肘部、前臂和手 | F3，或 Arm |
| ROV 正面全景 | 按整个 ROV 的范围取景，正面看到整机 | F4，或 ROV |

通过电脑 Unity Play + PICO Live Preview 使用时，电脑可辅助切摄像头和雷达参数；没有再给 A/B/X/右摇杆增加第二套用途。摄像头对象保存在 `Underwater_TaskConsole` 下，两区各三台，可以手工检查。当前每次只更新选中区域的一路预览：384 × 216、默认 8 Hz、无 XR 立体渲染、不渲染 UI，避免画中画递归。该更新率只指预览，不是头显目标帧率。隐藏面板后停止额外预览渲染。

## 新组合键优先级

- 左 Grip + 左 Y：面板隐藏 / 显示，任意按下顺序均支持；按住不会反复切换，再次触发需松开两键。
- 单独左 Grip：松开时雷达开始 / 停止。
- 单独 Y：松开时发一次气泡。
- 组合键已触发时，两键的单独动作均取消，避免面板一隐藏又开关雷达或冒气泡。
- F1 是电脑显示/隐藏面板；F6 只显示/隐藏雷达距离带。

此前定义的左摇杆、X 切区、右摇杆移动 ROV、右 Grip 控腕、手套控手全部保留。A 灯、B 尾流、左右扳机声音、左右摇杆点击的用途继续保留。

## 网络模型与任务摆放

每个区域的手下方附近放置 3 个海星、2 个鱿鱼，共 10 个目标。海星最大尺寸约 22 cm，鱿鱼长约 28 cm；模型与材质可手动调整。目标地面位置按当前碰撞表面向下采样，默认保留小间隙再自然落地。

模型来源：

- **Starfish，Poly by Google**：[Poly Pizza](https://poly.pizza/m/6H-0K9IEr56)，CC BY 3.0。选取橙色变体、居中、缩放、转为 Unity OBJ，保留原纹理。
- **Squid，Quaternius**：[Poly Pizza](https://poly.pizza/m/gReSPnGdkr)，CC0。改成水平摆放，缩放、转为 Unity OBJ，保留原纹理图集。这是静态风格化鱿鱼，不是软体生物动力学模型。

文件位于 `Assets/Underwater/MarineAssets`，其中 `ATTRIBUTION.md` 保存来源与许可。分享场景、素材和组会截图时保留海星署名。目标位于 `Marine Grasp Targets` 下，可直接手调位置、大小、碰撞代理。

## 抓取逻辑与操作

保留 Network UDP 5555 → UdexReal → WA100 关节映射。闭合量使用映射器输出的关节目标按限位归一化后求平均，不用手柄按钮模拟正式手套输入。

状态流程：张手待抓 → 靠近 → 拇指和至少一根手指接近目标 → 稳定闭合 → 持有 → 抬高 → 移到投放标记 → 张手释放。

1. 先连接手套，在现有链路中完成张手中立姿态标定。首次张手使本次抓取解锁；闭手路过目标不会凭空吸附。
2. 用 ROV 正面画面观察整机，右摇杆将当前区域的 ROV 移到合适位置；靠近目标后松开摇杆。
3. 切整臂画面，按住右 Grip，通过右手柄相对位姿控制末端，避免肘部先碰地；松开 Grip 后保持机械臂姿态。
4. 切抓取近景，把手掌靠近目标。默认目标表面距掌心不超过 6.5 cm，且拇指及至少一根指定手指也接近同一个目标。
5. 手套闭合量达到 0.32 并稳定至少 0.22 s 后才抓住；不是触碰一下就吸附。目标保持当时相对手腕的位置，不跳到手心中心。
6. 抬起至少 12 cm，面板出现 `HOLD / lifted`。把目标移到地面投放标记上方，距标记中心 0.4 m 内张手。
7. 闭合量低于 0.16 时释放，恢复动态刚体及地面碰撞。已验证抬起、且在投放区释放，才计为 `DELIVERED`。单纯碰到目标或闭手不算完成。
8. 切区、禁用任务或手套数据超过 1 s 未更新时释放，避免断链后目标继续粘住。测试音不会参与抓取。

这里的抓取是带距离、对向接触与时间门槛的软件约束，持有时用运动学刚体跟随手腕；它没有求解接触摩擦锥、柔软物体形变、抓取力闭合或真实夹持力。碰撞代理采用小型 BoxCollider，轮廓近似；可在 Inspector 调 `nearDistance`、闭合/张开阈值、稳定时间。建议先从一只海星开始调参。

F5 为无新鲜手套数据时的电脑调试闭手/张手模拟：仍需目标靠近，但跳过真实对向手指接触。真实手套数据恢复时自动退出辅助。它用于排查程序，不属于真实手套成功验收。断链、切区及禁用造成的释放不计投放成功。

## 整条机械臂防穿地

新增 `UnderwaterArmSurfaceGuard`，保护根为机械臂首关节，即 Axis1p 对应子树，覆盖其下方的可见网格与 WA100。原来的 WA100 检查把手看作相对手腕的形状；现在每个连杆都按自己的真实候选位姿检查，避免末端没碰地而肘部穿地。

每次 IK 后，在原姿态与候选姿态间以不超过约 0.25° 的关节插值步检查：逐网格方向包围盒重叠、穿透深度及平移扫掠；遇到新接触或更深穿入时退回上一个可接受姿态。每个连杆与每个环境面的接触单独记录，已有接触允许退出，不能用另一个连杆的初始重叠掩盖新穿透。ROV 平移也检查整臂；持有的目标随腕部进入同一防碰撞集合。

该方法使用保守包围盒，可能比视觉网格稍早停下，skin 默认 3 mm。右手触觉请求继续沿既有 XR 触觉接口发送，实际短震需要 PICO Live Preview 提供触觉支持。不要在 Inspector 中强行把机器人或地面瞬移到彼此内部；那种编辑态初始穿插应先人工移开。

## 雷达怎样与抓取协作

本项目的雷达仍是理想几何射线测距，不输出真实电磁回波，也没有物种识别能力。

| 阶段 | 建议模式 | 操作与正确表现 |
|---|---|---|
| 接近作业区 | 前视测距，Near structure / Wide survey | 看前方礁石与障碍，缓慢移动 ROV；不能只凭中央束判断两侧安全 |
| 手到目标上方 | F11 切腕部测距 | 使用独立的腕边测量原点，从掌心上方 0.20 m 朝下扫描；面板标 `WRIST` |
| 下探与对准 | Grasp close，量程 2 m、90° × 60°、81 × 21 束 | 等完整帧更新，看地面/目标轮廓与相对距离，再用近景确认拇指和指尖接触 |
| 闭手抓取 | 近景 + 对向接触状态 | 达到距离、闭合和稳定门槛后出现 HOLD；雷达有命中本身不会触发抓取 |
| 抬高与搬运 | 整臂/整机画面 + 碰撞保护 | 确认连杆与目标均离地，慢速搬到标记；张手完成投放 |

腕部距离从腕边传感器原点量起，**不等于手指到目标的间隙**。手到地面时，中央束读数也不应强求为零；传感器本身比掌心高约 20 cm。目标被抓住后作为机器人后代被自身过滤，不再当成外部障碍回报。

F11 或电脑展开的 Radar settings 切前视/腕部模式；切换清空旧帧，等待新完整帧。Snapshot 记录各自真实原点和姿态，两个模式的局部点云不能直接叠加当成同一世界地图。F9 导出 JSON/CSV/PLY；前视模式可按原指南用 5 m 靶校验，腕部模式先用已知平板高度做短距校验，不能沿用前视方向的水平位移公式。

JSON 新增 `scanMode=front/wrist_down`；腕部模式 `tiltDegrees=-90`，真实世界姿态以该帧 `rotation` 为准。默认最近有效距离 0.15 m，传感器高于掌心 0.20 m；抬起物体后，它会被自身过滤，不能把命中消失误判成抓取成功。成功仍由任务的 HOLD、抬高与 DELIVERED 条件判定。

推荐实验：固定目标，分别记录腕部原点到地面的已知高度、中央束测距、抓取状态及摄像头截图；比较开/关腕部测距时的任务完成时间、首次抓取成功率、触地次数和投放成功数。先做人工对照实验，不把几何测距称为自动抓取规划。

## 验证范围

本轮在 Unity Editor 中检查：两区六路单目画面、面板隐藏后的渲染停止、组合键优先级、整臂与薄地面的阻挡、近距抓取的稳定门槛、抬高与投放、远距/过期数据拒绝，以及原测距导出链路。抓取测试使用明确标记的桌面辅助输入；真实手套的对向接触门槛、PICO 面板可读性、触觉及总帧率仍需佩戴验证。

最终记录：Runtime/Editor 编译无错误；抓取与相机 Play 检查 40 项通过、无捕获错误；原雷达两区 Play 回归通过；场景导入检查 143 项、数学/Physics 检查 1,880 项、保存结构检查 5,419 项通过。固定靶实测 5.00 m，ROV 靠近后 4.74 m，与测试位移相符。这些数量是软件断言数量，不是实际佩戴试验次数。完整报告：[GRASP_TASK_VALIDATION.json](GRASP_TASK_VALIDATION.json)。

Live Preview 广告运行状态但缺少有效眼部渲染通道时，Editor 主相机会暂时单目显示，并在渲染通道恢复时自动恢复 XR；没有禁用头显位姿驱动。辅助摄像头始终非 XR。

任务事件写入 `Logs/GraspTask/events.jsonl`（构建中为 persistentDataPath/GraspTask），包含抓取/释放、目标 ID、位姿、闭合量及是否投放成功。自动检查记录位于 `Logs/GraspReview`，正式验证副本见本目录 JSON。
