# 当前固定按键定义

适用：`Assets/Underwater/Scenes/UnderwaterRadarSurveyEditable.unity`。更新：2026-10-28。

本次沙台与遥操作改进没有新增手柄按键。右 Grip 继续相对控腕；左右轴向、滤波与加速度限制改进见 [沙台抓取与机械臂遥操作改进](沙台抓取与机械臂遥操作改进.md)。

以用户已经确认的观察者移动、切区、ROV 移动、机械臂和手套定义为准。雷达用左 Grip 单独启停；旧雷达组合键取消。本轮按要求增加左 Grip + Y 隐藏/显示紧凑任务面板，组合键优先于两个单键动作。Grip 是手柄侧握键，Trigger 是食指扳机。

## PICO 手柄

| 输入 | 唯一用途 | 操作方式与结果 |
|---|---|---|
| 左摇杆 ↑ | 观察者上升 | 世界竖直向上，不是移动 ROV |
| 左摇杆 ↓ | 观察者下降 | 世界竖直向下 |
| 左摇杆 ← | 观察者拉近 | 沿当前视线的水平前向靠近 |
| 左摇杆 → | 观察者推远 | 沿当前视线的水平后向退开 |
| 左 X | 切换水池/自然海床 | 每次按下切一次；长按不重复 |
| 右摇杆 ↑ / ↓ | ROV 前进 / 后退 | 当前区域 ROV 的水平前向；不跟随头转 |
| 右摇杆 ← / → | ROV 左 / 右横移 | 当前区域 ROV 的水平侧向；默认不改变深度或偏航 |
| 右 Grip + 右手柄位姿 | 控机械臂末端位置与手腕姿态 | 按住后相对控制，松开保持；不是控制 WA100 手指 |
| UdexReal 手套 | WA100 手指动作 | 保留现有 Network UDP 5555 → 手套映射链路 |
| 左 Grip 单独 | 雷达开始 / 停止 | 松开时切换一次；长按不重复 |
| 左 Grip + Y | 任务面板隐藏 / 显示 | 两键同时按住触发一次，先后顺序均可；取消该次雷达和气泡单键动作；两键全松开后才可再触发 |
| 右 A | 工作灯开 / 关 | 左 Grip 按住与否，A 的用途不变 |
| 右 B | 尾流演示开 / 关 | 左 Grip 按住与否，B 的用途不变；不是 ROV 驾驶模式 |
| 左 Y 单独 | 发一组气泡 | 松开时发一次，长按不连续发射 |
| 左摇杆按下 | 切换性能档 | 三档循环；手动选择后退出自动降档 |
| 右摇杆按下 | 观察者传送瞄准 | 按住瞄准，松开在有效落点传送；不是移动 ROV |
| 右 Trigger | 声音测试 | 每次按下播放一次左右耳测试，同时恢复声音 |
| 左 Trigger | 静音 / 恢复 | 每次按下切换一次 |
| 系统 Menu / Home | PICO 系统用途 | 项目不重新占用 |

机械臂控制或传送瞄准期间暂停 ROV 平移，避免底座和手腕同时受控。传送过程中若按下右 Grip，取消本次传送；需松开摇杆点击后重新瞄准，避免结束控腕时意外传送。

左 Grip + A/B/左摇杆按下不再切雷达预设、俯仰或导出；A/B/性能键仍各自生效。只有用户指定的 Grip + Y 是面板组合键。例如单握左 Grip 后按 A，A 只切灯，松开 Grip 才切雷达。关闭 `GeometryRadar_System` 后，单独左 Grip 为空操作；Grip + Y 仍切任务面板。

## 本轮排查与修复

1. 取消旧雷达修饰键；仅保留 Grip + Y 面板组合，两个单键延迟到松开触发，保证任意按下顺序都不误触。
2. 输入在 `UnderwaterMotor` 提前统一读取，同一帧各系统使用相同快照和按下事件；长按只产生一次事件。
3. 不再在尾流、灯光、手腕脚本里分别读取另一套按钮状态。XR 特征可用时优先采用该设备，缺少特征时才回退 Input System，避免把不同来源直接 OR / 取较大摇杆值。
4. 停用 XR 模板的 ControllerManager、默认抓取/射线交互器及其他移动/转向提供器，避免握把、扳机、摇杆同时触发模板行为；保留手柄/头显位姿驱动和项目使用的传送提供器。
5. 保留两只 WA100 的 UdexReal 映射、机械臂 IK 与表面接触保护；新增 Axis1p 整臂保护和独立抓取任务，抓取由手套闭合及近距接触决定。

## 简单核对顺序

进入本场景 Play 后，先不握其他键：X 应只切一次区域；左摇杆只移动观察者；右摇杆只移动当前区 ROV。接着按住右 Grip，右摇杆应暂停 ROV，右手柄位姿控制末端。分别检查 A 灯、B 尾流、单独 Y 松开冒泡、左摇杆点击性能档；单独 Grip 松开启停雷达。最后 Grip + Y 应只切面板，雷达状态及气泡计数保持不变，分别交换按下顺序再验一次。

自动检查覆盖全部 256 种辅助按钮同时按下的状态、长按去重、面板组合的两种顺序和释放动作，以及实际 Play 中雷达启停、灯/尾流/气泡/性能档、声音、X 切区、ROV 移动与控腕互斥。真实 PICO 按键识别和手套连接仍需佩戴核对；日志见 `Logs/RadarReview`。完整抓取和三路摄像头操作见 [抓取任务与多视角操作指南](抓取任务与多视角操作指南.md)。
